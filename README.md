# 多指标背离分析系统（TradingView 复刻 + 扩展）

复刻并扩展了那张 TradingView 创业板指的图表思路：8 个技术指标的多指标共振背离检测 + 斐波那契回撤 + 布林带 + 滚动 Volume Profile，并在此基础上增加了**信号后验统计**、**数据缓存**、**趋势滤波（含 ADX）**、**交互式复盘 Dashboard**，以及一套**回测验证脚本**（参数网格 + 样本外验证）。

## 文件结构

```
.
├── tradingview_realization_v2.py   # 核心模块：指标、背离检测、趋势滤波、统计、绘图、批处理
├── dashboard.py                    # Streamlit 交互式复盘界面（需与核心模块同目录）
├── backtest_divergence.py          # 单标的回测：信号 → 滞后入场 → 持有 5/10/20 日 → 平仓
├── backtest_grid.py                # 参数网格：PIVOT_ORDER(3~6) × MIN_COUNT(3~6) + 热图
├── backtest_oos.py                 # 样本外验证：训练段选参数 → 测试段验证（趋势滤波 on/off 对照）
└── cache/                          # 行情缓存（自动生成），增量更新避免重复下载
```

## 快速开始

```bash
pip install yfinance pandas numpy scipy matplotlib plotly streamlit

# 批处理模式：跑一次，输出图表 + 统计 + 信号告警 CSV（默认已开趋势滤波）

# 样本外验证：训练段(2021-10~2024-12)选参数，测试段(2025-01~)检验

```

## 可调参数详解

所有参数集中在 `tradingview_realization_v2.py` 第 0 节，Dashboard 侧边栏可实时调节并联动重算。

### 背离信号参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `PIVOT_ORDER` | 3 | **pivot 灵敏度**。`argrelextrema` 判定局部高低点时的左右确认窗口（单位：K线根数）。调小（如 3）→ 小级别回调也算 pivot，信号变多变噪；调大（如 6~10）→ 只认显著转折点，信号少但可靠。**控制信号数量的首要旋钮** |
| `MIN_COUNT` | 3 | **共振指标数**。8 个指标（RSI/MACD柱/随机/动量/CCI/CMF/MFI/OBV）中至少几个同时出现背离才打标签。调大 → 信号极少但质量高（×6~8 通常对应重要顶底）；调小 → 信号多但假信号比例上升 |
| `DEDUP_BARS` | 10 | **去重窗口**。同方向信号在 N 根K线内只保留计数最高的一个。单边市里同一个顶部会产生一簇相邻信号，这个参数决定合并的松紧 |
| `STATS_HORIZONS` | (5, 10, 20) | 信号后验统计与回测的持有期（交易日）。看信号后 5/10/20 天的收益分布，判断信号的有效时间窗口 |

**背离判定逻辑**：对每对相邻 pivot 比较——底背离 = 价格 lower low 但指标 higher low；顶背离相反。单指标背离假信号很多，多指标共振（动量类 + 摆动类 + 成交量类同时衰竭）可靠性才够，这也是复刻原图"×N"标签的设计。

**确认延迟**：pivot 需要右侧 `PIVOT_ORDER` 根K线才能确认。Dashboard 后验统计表、收益分布与回测均按 **入场 = 信号 bar + `PIVOT_ORDER` 根收盘价**（`signal_returns` / `ENTRY_SHIFT`），无未来函数。

### 趋势滤波参数（新增）

| 参数 | 默认 | 作用 |
|---|---|---|
| `USE_TREND_FILTER` | True | 批处理/回测是否先对信号做顺势滤波。关闭则回到"全部信号参与统计与告警"的旧行为 |
| `TREND_MA_N` | 200 | 滤波均线周期（日线 200 / 周线 40）。价格在均线上方只留底背离（顺势买点），下方只留顶背离（顺势卖点） |
| ADX 阈值 | 关闭 | 仅 Dashboard 提供（关闭 / >20 / >25 / >30）。深绿/深红=趋势段（仅保留顺势背离）；**灰底震荡段顶/底背离全部保留**。启用后主图下方出现 ADX 指标条 |

`adx(df, n=14)` 与 `apply_trend_filter(df, bull_sig, bear_sig, ma_n, mode, adx_th)` 在核心模块中，可直接复用。注意 ADX 的语义是"确认趋势强度"而非"抑制反向信号"——顺势模式下逆势信号本来就不保留。

### 结构分析参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `LOOKBACK` | 160 | **斐波那契取哪段波段**。对最近 N 根K线的高低点计算 0.236/0.382/0.5/0.618 回撤位。波段选择决定一切：选最近一波推动浪最合理；设 `None` 用整段数据适合看长期结构 |
| `VP_WINDOW` | 60 | **滚动 Volume Profile 窗口**。第 t 天的 POC/VAH/VAL 只用过去 60 天数据计算，**无未来函数**，可直接当回测特征。调小 → 更贴近近期筹码；调大 → 更平滑稳定 |
| `VP_BINS` | 40 | Volume Profile 的价格分档数。调大 → 档位更细、渲染更精细；调小 → 更概括 |
| `BB_PERIOD` / `BB_STD` | 20 / 2.0 | 布林带周期/倍数。与背离配合使用：价格触及布林下轨 + 底背离共振，是经典的高胜率组合 |

### 回测参数（backtest_divergence.py）

| 参数 | 默认 | 作用 |
|---|---|---|
| `ENTRY_SHIFT` | =PIVOT_ORDER | pivot 确认滞后，信号后第 N 根收盘价入场（**不要改小，否则前视**） |
| `COST_BPS` | 0 | 单边交易成本（bps），往返一笔记 2× |
| 同向重叠 | 跳过 | 同一方向持仓期内的新信号不加仓；多/空各自独立核算 |

### 运行参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `TICKERS` | SPY、USDJPY=X、KBE、USO、TLT、GLD、EEM、SOXX、1810.HK | 批处理标的列表。支持美股、外汇（USDJPY=X，⚠️ Yahoo 外汇成交量恒为 0，Volume Profile 会退化）、港股（1810.HK）、A 股指数（000001.SS，Yahoo 数据质量一般建议换 akshare） |
| `PERIOD` | 5y | 数据区间。**信号统计建议至少 5 年**，2 年数据去重后信号太少，统计结论不可靠；有缓存后增量更新很快 |
| `SIGNAL_RECENT_DAYS` | 7 | "近 N 日信号"告警的截断窗口，输出到 `signals_recent.csv` |

## 输出文件

批处理每次运行生成一个以日期命名的目录（如 `2026-10-25/`）：

- `{ticker}.png` — 主图：K线 + MA/VWMA + 布林带 + 斐波那契 + 滚动 POC/VA + 趋势背景 + 背离标注 + 右侧 Volume Profile
- `returns_{ticker}.png` — 底/顶背离后验收益分布直方图（5/10/20 日三色）
- `stats_{ticker}.csv` / `signal_stats_all.csv` — 单标的/跨标的信号后验统计表
- `signals_recent.csv` — 近 7 日全标的信号告警
- `run_summary.csv` — 运行摘要

回测脚本输出在 `backtest/` 下：

- `backtest/<日期>/` — `backtest_divergence.py`：逐笔交易 CSV（多/空分开，5/10/20 日三档收益并列）+ 净值图（多空×三档持有期，虚线为买入持有基准）+ `backtest_summary.csv`
- `backtest/grid_<日期>/` — `backtest_grid.py`：16 组合汇总表 + 三张热图 + `best_pivot{p}_min{m}/` 最优组合明细
- `backtest/oos_<日期>/` — `backtest_oos.py`：滤波 on/off × 16 组合的 train/test 对照表 + 四面板图

## 图表约定

- **实心标注**（金底"底背离xN" / 紫底"顶背离xN"）：趋势滤波保留的顺势信号
- **"·逆"标注**（白底描边 / 空心三角，dashboard 为空心三角）：被滤波剔除的逆势信号，**仍在图上显示，供人工判断**
- **绿 / 红背景**：价格在滤波均线上方 / 下方（趋势开关打开时）
- **黄色虚线**：滤波均线 MA200（周线为 MA40）
- **ADX 条**（仅 dashboard，启用 ADX 过滤时显示）：虚线为阈值，线上方 = 趋势够强、信号保留

## 回测主要结论（2026-10-25，9 标的 × 5 年）

方法：pivot 确认滞后入场，持有 5/10/20 日，多空半仓等权、同向不重叠复利；参数网格 PIVOT_ORDER×MIN_COUNT 各 3~6；样本外按 2024-12 切分。

1. **信号在震荡/波段型资产上有效**（GLD、KBE、EEM、TLT 做多方向），在**强趋势型资产上是反指**（SOXX、1810.HK、SPY 的做空方向）——趋势滤波正是针对这一点。
2. **参数网格呈单调梯度**：越严格（大 pivot + 高 min_count）越好，最优格 p6/m6 全样本 +4.1%，但这主要是**样本内**结果。
3. **样本外验证泼了冷水**：无滤波时 16 个组合测试段全部亏损；train 冠军（p6/m6）测试段崩到 -0.2%。
4. **趋势滤波是正确方向的改进**：滤波后 test 段出现 2/16 个 train/test 双正组合——**p4/m3 与 p6/m3**（"大 pivot + 低共振数"，更像重要顶底警报器），且亏损幅度整体收窄。但 train 冠军在 test 依然失效（r≈0.4~0.5），**参数位置本身是噪音，不能靠回测选参数去交易**。

**定位**：这套系统适合当**复盘与警报工具**（配合纸上跟踪积累真实样本），不构成可自动执行的交易策略。

## Dashboard 使用

`streamlit run dashboard.py` 后浏览器打开 `http://localhost:8501`：

- 左侧选标的、调参数，**全部图表联动重算**；标的下拉自动合并缓存里出现过的 ticker，可直接输入新标的
- 侧边栏"趋势滤波"开关（默认开）+ ADX 强度下拉；统计区分"原始信号 / 趋势滤波后"两个 tab 并列对比
- 主图可框选缩放、悬停看数值；周末自动断开
- 统计表基于全量数据计算，不受"显示最近 N 根"的窗口裁剪影响
- 侧边栏展开面板"近 N 日有信号的标的"：按当前参数扫描全部标的（底背离绿字 / 顶背离红字）

## 解读指南

- **背离信号**提示动量衰竭，适合减仓/收紧止损，**不要单独用来反手**；强趋势里会连续失效（回测已证实）
- 趋势背景为绿色的区段，底背离的统计表现显著好于红色区段里的底背离（后者多半在接飞刀）
- **VA 带**内运行 = 筹码平衡区；价格贴着带上/下沿运行并带动整条带迁移 = 趋势延续信号
- **POC（控制点）** = 市场成本重心，价格在 POC 上方说明多数人浮盈，反之套牢
- 后验统计表里**底背离胜率长期低于 50% 的标的**（如部分商品），信号应反着用或过滤掉
